---
title: "Ignore Comment"
api: "POST https://api.velt.dev/v2/agents/checks/comments/ignore"
---

Use this API to ignore one comment of a check, with one of the four [ignore reasons](/api-reference/rest-apis/v2/agents/checks/overview#ignore-reasons). The comment becomes Ignored, with who, when and why. An agent's suggestion on it is marked `rejected`. When an agent finds the same problem again, the comment stays Ignored.

The comment can be an agent comment, or a person's comment [attached](/api-reference/rest-apis/v2/agents/checks/comments/attach) to a check. A person's comment that is not attached to a check is refused.

# Endpoint

`POST https://api.velt.dev/v2/agents/checks/comments/ignore`

# Headers

<ParamField header="x-velt-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField header="x-velt-auth-token" type="string" required>
  Your [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="organizationId" type="string" required>
      1 to 512 characters. The organization of the project.
    </ParamField>

    <ParamField body="documentId" type="string" required>
      1 to 512 characters. The document of the project.
    </ParamField>

    <ParamField body="annotationId" type="string" required>
      The comment annotation id. 1 to 512 characters, no `/`, and not `.` or `..`.
    </ParamField>

    <ParamField body="reason" type="string" required>
      `"wrong"`, `"not_important"`, `"not_applicable"` or `"cannot_tell"`.
    </ParamField>

    <ParamField body="userId" type="string" required>
      1 to 512 characters. Recorded as the person who ignored the comment.
    </ParamField>

    <ParamField body="feedbackReason" type="string">
      At most 2,000 characters. The person's own words, sent with the reason to the agent's feedback.
    </ParamField>
  </Expandable>
</ParamField>

The schema uses `.strict()`: unknown fields are rejected.

## **Example Requests**

```JSON
{
  "data": {
    "organizationId": "org_acme",
    "documentId": "acme-marketing-site",
    "annotationId": "K7mQ2xR9vB4wLdT1sYpN",
    "reason": "not_applicable",
    "userId": "user_sam",
    "feedbackReason": "This link is behind a login on purpose."
  }
}
```

# Response

#### Success Response

```JSON
{
  "result": {
    "status": "success",
    "message": "Comment ignored",
    "data": {
      "ignored": true
    }
  }
}
```

#### Failure Response

```JSON
{
  "error": {
    "message": "Only an agent comment can be resolved, ignored or reopened here",
    "status": "FAILED_PRECONDITION",
    "details": {
      "reason": "CHECKS_NOT_AGENT_COMMENT"
    }
  }
}
```

**Errors:** `INVALID_ARGUMENT` (a body outside the schema: a missing `annotationId` or `userId`, a `reason` outside the four, a `feedbackReason` over 2,000 characters, or an unknown field) / `NOT_FOUND` with `CHECKS_COMMENT_NOT_FOUND` (no such comment in the project) / `FAILED_PRECONDITION` with `CHECKS_NOT_AGENT_COMMENT` (a person's comment not attached to a check).
