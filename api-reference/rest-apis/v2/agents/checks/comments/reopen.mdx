---
title: "Reopen Comment"
api: "POST https://api.velt.dev/v2/agents/checks/comments/reopen"
---

Use this API to put a comment of a check back to Open, from Ignored or from Resolved (verified or not). The ignore, resolve and verify fields are cleared, so a later resolve is verified again. An agent's rejected suggestion on it is pending again.

Reopen is idempotent: a comment that is already Open or In progress keeps its status.

The comment can be an agent comment, or a person's comment [attached](/api-reference/rest-apis/v2/agents/checks/comments/attach) to a check. A person's comment that is not attached to a check is refused. See [Statuses](/api-reference/rest-apis/v2/agents/checks/overview#statuses).

# Endpoint

`POST https://api.velt.dev/v2/agents/checks/comments/reopen`

# Headers

<ParamField header="x-velt-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField header="x-velt-auth-token" type="string" required>
  Your [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="organizationId" type="string" required>
      1 to 512 characters. The organization of the project.
    </ParamField>

    <ParamField body="documentId" type="string" required>
      1 to 512 characters. The document of the project.
    </ParamField>

    <ParamField body="annotationId" type="string" required>
      The comment annotation id. 1 to 512 characters, no `/`, and not `.` or `..`.
    </ParamField>

    <ParamField body="userId" type="string" required>
      1 to 512 characters. Recorded as the person who reopened the comment.
    </ParamField>
  </Expandable>
</ParamField>

The schema uses `.strict()`: unknown fields are rejected.

## **Example Requests**

```JSON
{
  "data": {
    "organizationId": "org_acme",
    "documentId": "acme-marketing-site",
    "annotationId": "K7mQ2xR9vB4wLdT1sYpN",
    "userId": "user_sam"
  }
}
```

# Response

#### Success Response

```JSON
{
  "result": {
    "status": "success",
    "message": "Comment reopened",
    "data": {
      "reopened": true
    }
  }
}
```

#### Failure Response

```JSON
{
  "error": {
    "message": "Comment not found",
    "status": "NOT_FOUND",
    "details": {
      "reason": "CHECKS_COMMENT_NOT_FOUND"
    }
  }
}
```

**Errors:** `INVALID_ARGUMENT` (a body outside the schema: a missing `annotationId` or `userId`, or an unknown field) / `NOT_FOUND` with `CHECKS_COMMENT_NOT_FOUND` (no such comment in the project) / `FAILED_PRECONDITION` with `CHECKS_NOT_AGENT_COMMENT` (a person's comment not attached to a check).
