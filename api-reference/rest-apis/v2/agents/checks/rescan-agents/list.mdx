---
title: "List Rescan Agents"
api: "POST https://api.velt.dev/v2/agents/checks/rescan-agents/list"
---

Use this API to list the agents to run to rescan a project's site: the agents of its checks and of its runs in the last 30 days, so a site whose agents found nothing still names them. With `pages`, only the agents that checked one of those pages. When no agent checked any of them, every agent of the site is returned.

Run the agents with [Run Execution](/api-reference/rest-apis/v2/agents/execution/run). This endpoint starts nothing and charges nothing.

# Endpoint

`POST https://api.velt.dev/v2/agents/checks/rescan-agents/list`

# Headers

<ParamField header="x-velt-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField header="x-velt-auth-token" type="string" required>
  Your [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="organizationId" type="string" required>
      1 to 512 characters. The organization of the project.
    </ParamField>

    <ParamField body="documentId" type="string" required>
      1 to 512 characters. The document of the project.
    </ParamField>

    <ParamField body="pages" type="string[]">
      At most 1,000 absolute `http(s)` page URLs, each at most 2,048 characters. Without it, the agents of the whole site.
    </ParamField>
  </Expandable>
</ParamField>

The schema uses `.strict()`: unknown fields are rejected.

## **Example Requests**

#### 1. The whole site

```JSON
{
  "data": {
    "organizationId": "org_acme",
    "documentId": "acme-marketing-site"
  }
}
```

#### 2. Some pages

```JSON
{
  "data": {
    "organizationId": "org_acme",
    "documentId": "acme-marketing-site",
    "pages": [
      "https://www.example.com/pricing",
      "https://www.example.com/about"
    ]
  }
}
```

# Response

#### Success Response

```JSON
{
  "result": {
    "status": "success",
    "message": "Rescan agents retrieved",
    "data": {
      "agentIds": ["broken-links", "spell-check"]
    }
  }
}
```

| Field           | Type     | Description |
| --------------- | -------- | ----------- |
| `data.agentIds` | string[] | The agent ids, sorted. Empty when no agent has checked the site. |

#### Failure Response

```JSON
{
  "error": {
    "message": "pages must be a list of page URLs",
    "status": "INVALID_ARGUMENT",
    "details": {
      "reason": "CHECKS_INVALID_PAGES"
    }
  }
}
```

**Errors:** `INVALID_ARGUMENT` (a body outside the schema: a `pages` entry that is not a URL, more than 1,000 `pages`, or an unknown field; or `CHECKS_INVALID_PAGES` for a `pages` entry that is not `http(s)`) / `NOT_FOUND` with `CHECKS_WORKSPACE_NOT_FOUND` (the workspace has no store database).
