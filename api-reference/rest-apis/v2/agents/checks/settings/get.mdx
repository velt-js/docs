---
title: "Get Check Settings"
api: "POST https://api.velt.dev/v2/agents/checks/settings/get"
---

Use this API to get the checks settings the engine applies to a project: the confidence floor, your own flags and the default owners, and where they came from. Change them with [Update Check Settings](/api-reference/rest-apis/v2/agents/checks/settings/update).

# Endpoint

`POST https://api.velt.dev/v2/agents/checks/settings/get`

# Headers

<ParamField header="x-velt-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField header="x-velt-auth-token" type="string" required>
  Your [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="organizationId" type="string" required>
      1 to 512 characters. The organization of the project.
    </ParamField>

    <ParamField body="documentId" type="string" required>
      1 to 512 characters. The document of the project.
    </ParamField>
  </Expandable>
</ParamField>

The schema uses `.strict()`: unknown fields are rejected.

## **Example Requests**

```JSON
{
  "data": {
    "organizationId": "org_acme",
    "documentId": "acme-marketing-site"
  }
}
```

# Response

#### Success Response

```JSON
{
  "result": {
    "status": "success",
    "message": "Check settings retrieved",
    "data": {
      "confidenceFloor": 60,
      "hostFlags": {
        "weeklyDigest": true
      },
      "owners": {
        "dev": {
          "userId": "user_jordan",
          "name": "Jordan Lee",
          "email": "jordan@example.com"
        },
        "admin": {
          "userId": "user_sam"
        }
      },
      "source": "mirror",
      "updatedAt": 1761465600000
    }
  }
}
```

| Field                  | Type           | Description |
| ---------------------- | -------------- | ----------- |
| `data.confidenceFloor` | number         | 0 to 100. A finding under it writes no comment. Default: `50`. |
| `data.hostFlags`       | object         | Your own boolean flags. Stored and returned, never read by the engine. |
| `data.owners`          | object         | The default owner of a check by its responsibility (`content`, `design`, `dev`) and the fallback (`admin`), each `{ userId, name?, email? }`. Only the owners set with Update Check Settings are present. |
| `data.source`          | string         | Where the settings came from: `"mirror"` (set with Update Check Settings), `"host"` (the embedding product's own) or `"default"`. |
| `data.updatedAt`       | number \| null | When the settings were last updated (epoch ms), or `null` when never set. |

#### Failure Response

```JSON
{
  "error": {
    "message": "Workspace not found or has no store database for the checks engine",
    "status": "NOT_FOUND",
    "details": {
      "reason": "CHECKS_WORKSPACE_NOT_FOUND"
    }
  }
}
```

**Errors:** `INVALID_ARGUMENT` (a body outside the schema: a missing `organizationId` or `documentId`, or an unknown field) / `NOT_FOUND` with `CHECKS_WORKSPACE_NOT_FOUND` (the workspace has no store database).
