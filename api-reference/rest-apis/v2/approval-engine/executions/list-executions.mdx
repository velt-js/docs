---
title: "List Executions"
api: "POST https://api.velt.dev/v2/workflow/executions/list"
---

Use this API to paginate through workflow executions. Filter by `definitionId` and/or `status`.

# Endpoint

`POST https://api.velt.dev/v2/workflow/executions/list`

# Headers

<ParamField header="x-velt-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField header="x-velt-auth-token" type="string" required>
  Your [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="definitionId" type="string">
      Filter by definition.
    </ParamField>

    <ParamField body="status" type="string">
      Filter by status. One of: `pending` / `running` / `completed` / `failed` / `cancelled`.
    </ParamField>

    <ParamField body="pageSize" type="integer">
      1–500. Default 50.
    </ParamField>

    <ParamField body="cursor" type="string">
      The previous response's `nextCursor` (last item's `startedAt` epoch ms, as a string). Pass it back unchanged.
    </ParamField>

    <Note>
      `List Executions` does not accept `organizationId` or `documentId` filters. List items return `steps: []`; call [Get Execution](/api-reference/rest-apis/v2/approval-engine/executions/get-execution) with an `executionId` to load the step view models.
    </Note>
  </Expandable>
</ParamField>

## **Example Requests**

#### List running executions for a definition

```JSON
{
  "data": {
    "definitionId": "marketing-copy-approval",
    "status": "running",
    "pageSize": 50
  }
}
```

#### Paginate

```JSON
{
  "data": {
    "pageSize": 50,
    "cursor": "1777374504364"
  }
}
```

# Response

#### Success Response

```JSON
{
  "result": {
    "items": [ /* ExecutionView[], each with steps: [] */ ],
    "nextCursor": "1777374504364"
  }
}
```

`nextCursor` is `null` when the returned page is not full. Pagination ends there.

#### Failure Response

```JSON
{
  "error": {
    "message": "ERROR_MESSAGE",
    "status": "INVALID_ARGUMENT"
  }
}
```

<ResponseExample>
```js
{
  "result": {
    "items": [],
    "nextCursor": null
  }
}
```
</ResponseExample>
