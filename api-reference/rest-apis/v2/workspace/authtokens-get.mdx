---
title: "Get Auth Tokens"
api: "POST https://api.velt.dev/v2/workspace/authtokens/get"
---

Use this API to retrieve all auth tokens associated with a specific API key.

<Info>
This endpoint uses **workspace-level auth**: pass `x-velt-workspace-id` and `x-velt-workspace-auth-token` (from the Create Workspace response) as headers.
</Info>

# Endpoint

`POST https://api.velt.dev/v2/workspace/authtokens/get`

# Headers

<ParamField header="x-velt-workspace-id" type="string" required>
  Your Workspace ID.
</ParamField>

<ParamField header="x-velt-workspace-auth-token" type="string" required>
  Your workspace [Auth Token](/security/auth-tokens).
</ParamField>

# Body

#### Params

<ParamField body="data" type="object" required>
  <Expandable title="properties">
    <ParamField body="apiKey" type="string" required>
      The API key whose auth tokens should be retrieved.
    </ParamField>
  </Expandable>
</ParamField>

# Example Request

```JSON
{
  "data": {
    "apiKey": "velt_api_key_1"
  }
}
```

# Response

<ResponseField name="authTokens" type="object[]">
  The auth tokens for the API key.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique ID of the auth token.
    </ResponseField>
    <ResponseField name="token" type="string">
      The auth token value.
    </ResponseField>
    <ResponseField name="last4" type="string">
      The last four characters of the token.
    </ResponseField>
    <ResponseField name="name" type="string">
      Name of the auth token.
    </ResponseField>
    <ResponseField name="domains" type="string[]">
      Domains the token is restricted to.
    </ResponseField>
    <ResponseField name="createdAt" type="number | null">
      When the token was created, in epoch milliseconds. `null` when the creation time is not known.
    </ResponseField>
    <ResponseField name="lastUsedAt" type="number | null">
      When the token was last used, in epoch milliseconds. `null` when the token has no recorded use.
    </ResponseField>
  </Expandable>
</ResponseField>
