## How to add Velt attributes to TanStack Table cells?

Some Velt features like live selection require adding Velt specific attributes to the cell elements. TanStack Table is headless, so you render the table markup yourself. Add the Velt attributes directly to the cell elements you render.

1. In your column definitions, use the `cell` render function to customize the cell rendering.
2. Add the necessary Velt attributes to the element returned by the `cell` render function, or to the `<td>` element in your table markup.

Here's a code sample that shows how to add the `data-velt-live-selection-enabled` attribute and other required attributes to TanStack Table cells:

```jsx
const columns = [
  {
    accessorKey: 'FIELD_NAME',
    cell: (info) => (
      <div
        data-velt-live-selection-enabled="true"
        // Add other Velt attributes as required
      >
        {info.getValue()}
      </div>
    ),
  },
];
```

Alternatively, add the attributes to the `<td>` elements when rendering rows:

```jsx
<tbody>
  {table.getRowModel().rows.map((row) => (
    <tr key={row.id}>
      {row.getVisibleCells().map((cell) => (
        <td
          key={cell.id}
          data-velt-live-selection-enabled="true"
          // Add other Velt attributes as required
        >
          {flexRender(cell.column.columnDef.cell, cell.getContext())}
        </td>
      ))}
    </tr>
  ))}
</tbody>
```
