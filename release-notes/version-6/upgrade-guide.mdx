## 6.0.28

### setLocations replaces the location set

`client.setLocations()` now replaces the existing additional locations with the locations in the call, unless you pass `appendLocation: true`. `setLocation`, `setRootLocation`, and `addLocation` still add locations.

Update any code that calls `setLocations` more than once and relies on the earlier locations being kept.

<Tabs>
<Tab title="React / Next.js">

**Before:**
```jsx
client.setLocations([{ id: 'en', locationName: 'English' }]);
client.setLocations([{ id: 'es', locationName: 'Spanish' }]);
// Root became `es`. Additional location `en` was kept.
```

**After:**
```jsx
client.setLocations([{ id: 'en', locationName: 'English' }]);
client.setLocations([{ id: 'es', locationName: 'Spanish' }]);
// The set is only `es`. `en` is removed.

// To keep the previous merge behavior:
client.setLocations([{ id: 'es', locationName: 'Spanish' }], { appendLocation: true });
```

</Tab>
<Tab title="Other Frameworks">

**Before:**
```js
Velt.setLocations([{ id: 'en', locationName: 'English' }]);
Velt.setLocations([{ id: 'es', locationName: 'Spanish' }]);
// Root became `es`. Additional location `en` was kept.
```

**After:**
```js
Velt.setLocations([{ id: 'en', locationName: 'English' }]);
Velt.setLocations([{ id: 'es', locationName: 'Spanish' }]);
// The set is only `es`. `en` is removed.

// To keep the previous merge behavior:
Velt.setLocations([{ id: 'es', locationName: 'Spanish' }], { appendLocation: true });
```

</Tab>

### removeLocations matches a location by id

`client.removeLocations()` now removes a root or additional location that matches the `id` you pass, even when you set it with more fields. A call that passes the full location object still works.

If you pass only `{ id }` and relied on it matching nothing, the location is now removed.

<Tabs>
<Tab title="React / Next.js">

**Before:**
```jsx
client.setLocations([{ id: 'es', locationName: 'Spanish' }]);
client.removeLocations([{ id: 'es' }]);
// No removal. The location stayed subscribed.
```

**After:**
```jsx
client.setLocations([{ id: 'es', locationName: 'Spanish' }]);
client.removeLocations([{ id: 'es' }]);
// The Spanish location is removed.
```

</Tab>

**Before:**


**After:**
