## Breaking Changes

### Suggestion metadata moved to `suggestion.metadata`

In 6.0.21, `CommitSuggestionConfig.metadata` is stored at `annotation.suggestion.metadata`, not `annotation.metadata`. `Suggestion.metadata` returns only your keys, without SDK keys such as `apiKey`, `documentId`, `sdkVersion`, and `pageInfo`.

Suggestions saved before 6.0.21 keep your keys on `annotation.metadata`.

**Before:**

<Tabs>
<Tab title="React / Next.js">
```jsx
const ticket = annotation.metadata.ticket;
```
</Tab>
<Tab title="Other Frameworks">
```js
const ticket = annotation.metadata.ticket;
```
</Tab>
</Tabs>

**After:**

<Tabs>
<Tab title="React / Next.js">
```jsx
// Handles rows written by both versions
const ticket = annotation.suggestion?.metadata?.ticket ?? annotation.metadata?.ticket;
```
</Tab>
<Tab title="Other Frameworks">
```js
// Handles rows written by both versions
const ticket = annotation.suggestion?.metadata?.ticket ?? annotation.metadata?.ticket;
```
</Tab>
</Tabs>

### Self-hosted comment resolvers must persist `suggestion`

With a comment data provider, Velt no longer stores suggestion content. Your resolver does, and `comment_annotation.suggestion_reject` is now sent without an `additionalSaveEvents` opt-in. Update your backend before or with this upgrade. See [Suggestion Content](/self-hosting/partial/comments#suggestion-content).

**Before:**

<Tabs>
<Tab title="React / Next.js">
```jsx
// Content was on the Velt comment document
const summary = veltAnnotation.suggestion.summary;
```
</Tab>
<Tab title="Other Frameworks">
```js
// Content was on the Velt comment document
const summary = veltAnnotation.suggestion.summary;
```
</Tab>
</Tabs>

**After:**

<Tabs>
<Tab title="React / Next.js">
```jsx
// Content is in your resolver's save and get
async function save(request) {
  const annotation = Object.values(request.commentAnnotation)[0];
  const summary = annotation.suggestion?.summary;
  return { statusCode: 200, success: true, data: undefined };
}
```
</Tab>
<Tab title="Other Frameworks">
```js
// Content is in your resolver's save and get
async function save(request) {
  const annotation = Object.values(request.commentAnnotation)[0];
  const summary = annotation.suggestion?.summary;
  return { statusCode: 200, success: true, data: undefined };
}
```
</Tab>
</Tabs>

Hosted projects keep suggestion content on the Velt document. No change is required.
