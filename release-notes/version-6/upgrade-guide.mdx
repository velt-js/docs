## Overview

- **Key change in this series**:
  - The paginated contact list is on by default (6.0.27).

## Breaking Changes

- [**Comments**] The paginated contact list is on by default. If you never called `enablePaginatedContactList()`, each contact list now loads 10 users plus the signed-in user. Users outside that page are found through @mention search.

## How to Upgrade

To keep the previous behavior, turn the paginated contact list off.

<Tabs>
<Tab title="React / Next.js">
**Before:**

```jsx
import { useVeltClient } from '@veltdev/react';

const { client } = useVeltClient();
const commentElement = client.getCommentElement();
commentElement.enablePaginatedContactList(); // opt in to 10 users per list
```

**After:**

```jsx
import { VeltComments } from '@veltdev/react';

<VeltComments paginatedContactList={false} />
```

Or call the API method:

```jsx
const commentElement = client.getCommentElement();
commentElement.disablePaginatedContactList(); // restore the full list
```
</Tab>
<Tab title="Other Frameworks">
**Before:**

```js
const commentElement = Velt.getCommentElement();
commentElement.enablePaginatedContactList(); // opt in to 10 users per list
```

**After:**

```html
<velt-comments paginated-contact-list="false"></velt-comments>
```

Or call the API method:

```js
const commentElement = Velt.getCommentElement();
commentElement.disablePaginatedContactList(); // restore the full list
```
</Tab>
</Tabs>

<Note>
@mention search relies on indexes on `user.name_lowercase` and `user.email_lowercase`. Without them, search returns nothing and only the first 10 users can be mentioned.
</Note>
